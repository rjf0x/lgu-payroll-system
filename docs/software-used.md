# Software Used in the LGU Payroll Management System

Verified on November 11, 2026 against the local environment, installed dependencies, and repository configuration. Installed versions describe this workstation; pinned container versions describe the project's configuration.

| Software / technology | Version | Purpose in the system |
|---|---|---|

| Laravel | 13.40.0 | Backend framework providing routing, authentication infrastructure, Eloquent database access, migrations, queues, scheduling, and application services. |

The application uses Blade and native JavaScript rather than a separate React or Vue frontend. Spreadsheet reports are generated by the application's PHP service using `ZipArchive` and Office Open XML; browser printing supports printable reports and payslips.

## Database and storage

| Software / technology | Version | Purpose in the system |
|---|---|---|
| MySQL | 8.4.3 on the connected local database | Stores employee records, compensation, payroll, approvals, deductions, reports, audit logs, and blockchain registration metadata. |
| SQLite | Bundled runtime support; separate version not checked | Stores the Node bridge's durable transaction journal. In-memory SQLite is also the default database for automated PHP tests. |
| Node.js `node:sqlite` | Included with Node.js | Provides SQLite access for the bridge journal without an additional SQLite JavaScript package. |

The configured database queue runs payroll registration jobs. MySQL remains the source of confidential payroll data; the bridge journal preserves transaction state for recovery and retries.

## Blockchain and integration

| Software / technology | Version | Purpose in the system |
|---|---|---|
| Hyperledger Besu | 26.10.2, pinned Docker image | Runs the private Ethereum-compatible network that stores finalized payroll hashes and registration metadata. The local stack has four QBFT validators. |
| Web3Signer | 26.10.2, pinned Docker image | Signs blockchain transactions using the configured signing account. |
| Solidity | 0.8.30 | Language used for the payroll integrity registry and supporting smart contracts. |
| Solidity compiler (`solc`) | 0.8.30, pinned Docker image | Compiles Solidity contracts for deployment and contract tests. |
| Node.js | 26.13.0 locally | Runs the private blockchain bridge, deployment utilities, journal utilities, and JavaScript tests. |
| ethers.js | 6.17.0 | Communicates with Besu and Web3Signer, encodes contract calls, and validates transaction and registration evidence. |
| JSON-RPC and HTTP | Protocols | Connect the bridge to blockchain nodes and signing services, and connect Laravel to the bridge. |
| SHA-256 | Hash algorithm | Creates the deterministic payroll fingerprint registered on the blockchain. |

Payroll Verification compares a fresh hash of saved payroll data with the blockchain evidence. Employee names, salaries, and detailed deductions remain in MySQL; they are not published as payroll details on-chain.
